1. Introduction                               *fugitive-difftool-introduction*

fugitive-difftool.nvim completes |fugitive|'s `:Git difftool` integration.
It lets you compare two revisions of a repository using the |quickfix| list,
which is useful for code reviews: load a full diff between two branches or
commits, then step through every changed file one at a time.

This plugin requires vim-fugitive to be installed and does not work as a
standalone plugin.

==============================================================================
2. Usage                                      *fugitive-difftool-usage*

Run a `:Git difftool` command with `--name-status` so that one entry is
added to the |quickfix| list per changed file, rather than per hunk:
>
    :Git! difftool --name-status master...my-feature
<
The `!` prevents Vim from jumping to the first |quickfix| entry immediately;
jump explicitly once the list has finished loading, using one of the
|fugitive-difftool-commands|.

Note the `...` between the two refs: this diffs the tip of `my-feature`
against its merge base with `master`, showing only the changes introduced
by the feature branch rather than a full two-dot diff.

==============================================================================
3. Suggested Commands                         *fugitive-difftool-commands*

                                              *:Gcfir*
:Gcfir                  Jump to the first entry in the |quickfix| list.

                                              *:Gcla*
:Gcla                   Jump to the last entry in the |quickfix| list.

                                              *:Gcn*
:Gcn                    Jump to the next entry in the |quickfix| list.

                                              *:Gcp*
:Gcp                    Jump to the previous entry in the |quickfix| list.

                                              *:Gcc*
:Gcc                    Jump to the currently selected |quickfix| entry.

To set up the suggested commands, add the following to your config:
>lua
    vim.api.nvim_create_user_command(
      "Gcfir", require("fugitive-difftool").git_cfir, {}
    )
    vim.api.nvim_create_user_command(
      "Gcla", require("fugitive-difftool").git_cla, {}
    )
    vim.api.nvim_create_user_command(
      "Gcn", require("fugitive-difftool").git_cn, {}
    )
    vim.api.nvim_create_user_command(
      "Gcp", require("fugitive-difftool").git_cp, {}
    )
    vim.api.nvim_create_user_command(
      "Gcc", require("fugitive-difftool").git_cc, {}
    )
<

==============================================================================
4. Lua API                                    *fugitive-difftool-api*

The module `require("fugitive-difftool")` exposes the following functions for
navigating the |quickfix| list. Each takes no arguments and is suitable for
passing directly to |nvim_create_user_command()|.

                                              *fugitive-difftool.git_cfir()*
`git_cfir()`    Jump to the first entry in the |quickfix| list. See |:Gcfir|.

                                              *fugitive-difftool.git_cla()*
`git_cla()`     Jump to the last entry in the |quickfix| list. See |:Gcla|.

                                              *fugitive-difftool.git_cn()*
`git_cn()`      Jump to the next entry in the |quickfix| list. See |:Gcn|.

                                              *fugitive-difftool.git_cp()*
`git_cp()`      Jump to the previous entry in the |quickfix| list. See |:Gcp|.

                                              *fugitive-difftool.git_cc()*
`git_cc()`      Jump to the currently selected |quickfix| entry. See |:Gcc|.
